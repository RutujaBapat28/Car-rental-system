# Car Rental System

## Project Description
The Car Rental System is a web-based application developed to simplify the process of renting and managing cars.

## Features
- User-friendly car rental system
- Car booking management
- Customer details management
- Car availability management
- Simple and easy-to-use interface

## Technologies Used
- Python
- HTML
- CSS
- JavaScript
- MySQL

## How to Run
1. Download or clone the repository.
2. Install the required dependencies.
3. Configure the database.
4. Run the application.
5. Open the application in a web browser.

## Project Purpose
The main purpose of this project is to provide an easy and efficient platform for managing car rentals digitally.
